# MERN Lab Tasks

A collection of MERN Stack laboratory projects developed as part of academic coursework.

## Projects

### 1. CRUD Operations
- Perform Create, Read, Update and Delete operations.
- Frontend using HTML and CSS.
- Backend using Express.js and REST API.

### 2. User SignUp Page
- User signup and registration.
- Backend using Node.js and Express.js.
- MongoDB database integration.

- Node.js
