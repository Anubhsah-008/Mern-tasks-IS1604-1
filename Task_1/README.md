# InventoryRoom — Item Management System

## Project Description

This is a simple Item Management System built with Express.js. It provides a REST API for performing CRUD (Create, Read, Update, Delete) operations on items. The application includes:

- A backend server with RESTful API endpoints
- A frontend interface for managing items
- In-memory data storage for simplicity

## Features

- **View Dashboard**: Display all items in a user-friendly dashboard
- **Add Items**: Create new items with name and price
- **Update Items**: Modify existing item details
- **Delete Items**: Remove items from the list

## API Endpoints

- `GET /api/items` - Get all items
- `GET /api/items/:id` - Get a single item by ID
- `POST /api/items` - Create a new item
- `PUT /api/items/:id` - Update an existing item
- `DELETE /api/items/:id` - Delete an item

## Installation & Usage

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
npm start
```

3. Open your browser and navigate to:

```
http://localhost:3000
```
